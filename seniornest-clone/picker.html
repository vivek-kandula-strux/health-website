Six complete homepages. One brand. Pick the direction.

Every variant carries the same copy, the same nav, the same testimonials, the same FAQ. Only the design language changes — and within each variant, every section obeys one through-line so the page never feels stitched together.

Through-line discipline

Why none of these feel stitched together.

Every variant locks five decisions and applies them across every section — hero, mission, about, why, services, process, gallery, team, testimonials, principles, FAQ, CTA, footer. Same content, same nav, same brand purple. Only the design language shifts.

One radius24px bento · 28px glass · 20px gradient · 4px minimal · 4-8px dark · 0px Swiss
One shadowWarm soft · cinematic deep · gradient glow · none · subtle gold halo · none
One imagery treatmentRounded crops · full-bleed atmospheric · duotone wash · edge-aligned natural · B&W luxury · grayscale 1:1
One motion grammarCard-lift · parallax depth · gradient drift · ultra-restrained · slow gold reveals · click ripple
One headline rhythmFraunces in V1–V6 · Inter (Helvetica substitute) in V7 Swiss
